# Shaheen Welfare Society Website

Official website for **Shaheen Welfare Society, Sargodha** — a community-driven non-profit organization dedicated to empowering marginalized groups, strengthening governance, and promoting social equity in Pakistan since 2001.

## About Shaheen Welfare Society

**Shaheen Welfare Society** is a registered voluntary social welfare agency (under the Voluntary Social Welfare Agencies Ordinance, 1961) based in **Chak No. 15/SB, District Bhalwal, Sargodha, Punjab, Pakistan**.

### Vision
To support marginalized communities and specialized groups by providing technical expertise, fostering sustainable linkages, and promoting institutional autonomy. The organization has established a Research and Training Center to enhance knowledge, innovation, and community empowerment.

### Mission
To develop society through participatory, integrated, and sustainable development approaches that ensure the transfer of power to communities.

### Core Values
- **Transparency & Accountability**
- **Equity & Inclusion**
- **Community Ownership**
- **Human Rights & Gender Equality**
- **Participatory Decision-Making**

## Focus Areas

### 1. Women's Empowerment
Empowering women socially, politically, and economically by promoting equal opportunities and strengthening their leadership roles in society.

### 2. Decentralized Governance
Integrating rights-based initiatives into local governance and grassroots-level structures to ensure accessibility and community participation.

### 3. Partnership for Social Equity
Promoting equity through collaboration between civil society, government, and communities to address marginalization, strengthen trust, and enhance social justice.

## Website Development

This is a [Next.js](https://nextjs.org/) project for the Shaheen Welfare Society website.

### Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Start production server
npm start
```
